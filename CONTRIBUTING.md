## 💬 General Support & Questions

If you have questions about how to use Luminous, configuration help, or general ideas, **please use GitHub Discussions instead of opening an issue**.

* 💬 [GitHub Discussions](https://github.com/esoltys/luminous/discussions)

If it's vague "How about a...?" or "I don't know..." then use discussions. If your bug or feature request is clearly defined then continue below:

---

## 🐛 Reporting Bugs

Before submitting a bug report, please **search existing issues** to ensure it hasn't already been reported.

If you encounter a new bug, please open a report using our structured form:

1. Go to the **Issues** tab and click **New Issue**.
2. Select **🐛 Bug Report**.
3. Complete the required fields, including:
* **OS & Version** (e.g., Windows 11, Kubuntu 24.04, macOS)
* **Steps to Reproduce** (clear, numbered instructions)
* **Expected vs. Actual Behavior**
* **Relevant terminal logs or screenshots** (if applicable)

> **Note:** Please do not delete required sections from the bug report template, as incomplete reports make it difficult to diagnose and resolve issues efficiently.

---

## ✨ Suggesting Features

Did I miss something you'd like to see? To propose a feature:

1. Check existing open and closed issues to avoid duplicate requests. Maybe I have it pencilled in for a future milestone?
2. Go to the **Issues** tab, click **New Issue**, and choose **✨ Feature Request**.
3. Describe the problem or pain point you're trying to solve, followed by your proposed solution.
