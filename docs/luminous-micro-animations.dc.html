Motion spec — celebration moments
Small joyful animations for the moments Luminous should feel good about — favouriting, adding music, organizing, and playlists. Motion carries the same visual hierarchy as type: bigger, warmer moves for milestones; quieter pops for routine confirmations; sharp, brief moves for warnings. Demos below loop continuously.
The hierarchy
Four tiers, same way type has display/heading/body weights. Reduce motion, size, and duration as the tier goes quieter; increase reach only for the moments that deserve it.
Milestone
Rare, personal achievements. Biggest scale, warmest color, longest reach — but still one motion, not a shower of them.
Duration 600–700ms · Scale up to 1.22×
Easing overshoot spring
Sound 3-note rising arpeggio, ~280ms
New
Something appeared that wasn't there before — a playlist, a folder, a badge. Materializes gently; invites a look, doesn't demand one.
Duration 350–450ms · Scale 0.92×→1×
Easing ease-out, slight overshoot
Sound single soft blip, ~100ms
Success
Routine confirmations — a favourite, a finished import. Quick and light; it should read as "done," not as a celebration.
Duration 250–350ms · Scale up to 1.1×
Easing ease-out
Sound rising third, two notes, ~120ms
Warning / error
Needs attention. Sharp and brief — no bounce, no overshoot. A nudge, not a celebration.
Duration 180–220ms · Scale none
Easing linear / ease-in-out
Sound single low blip, ~150ms

Reduced motion
When the OS "reduce motion" setting is on, every animation above collapses to the same fallback: a plain opacity fade, no scale, no bounce, no rings. Toggle it to compare.

Sound cues
Optional, off by default, one toggle in Settings mutes all of them. Keep every cue under ~150ms and pitched from the same small set of tones so they feel like one instrument, not a pile of stock effects.
