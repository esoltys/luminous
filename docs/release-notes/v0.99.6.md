# Release Notes - Luminous v0.99.6

Patch release fixing an album-year data loss bug, a Windows blank-window bug, and a
Linux AppImage self-update issue.

### 🐛 Bug Fixes
- **Album year lost for ID3v2-tagged files**: the lofty 0.25 bump changed how year tags
  were read, silently returning no year for ID3v2-tagged files (nearly all MP3s). A
  subsequent library rescan then wiped the `year` column in the database for affected
  songs — files on disk were never touched, but the app's own copy of the metadata was
  lost. Reads and writes now go through lofty's `date()`/`set_date()` accessors, which
  correctly check the ID3v2 `TDRC` frame before falling back to the legacy ID3v1 year
  field. ([#453](https://github.com/esoltys/luminous/issues/453))
- **Blank window after restoring from minimized (Windows)**: minimizing the app and
  leaving it in the background for 30–60+ seconds, then restoring it, could leave the
  window completely blank/white. Chromium/WebView2 was suspending its rendering pipeline
  while occluded and failing to resume on restore; window-state persistence and
  minimized-window geometry capture had related issues. All three are fixed.
  ([#441](https://github.com/esoltys/luminous/issues/441))
- **Self-update offered on AppImage installs**: Linux AppImage builds incorrectly
  reported themselves as self-updatable, offering in-app download/install for a format
  that can't be patched in place. AppImage installs are now treated like other
  externally-managed formats (deb/rpm/flatpak/snap/Microsoft Store): the app notifies of
  new releases and points users to GitHub Releases instead.
  ([#411](https://github.com/esoltys/luminous/issues/411))
