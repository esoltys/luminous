# Release Notes - Luminous v0.99.2

Patch release fixing a Linux AppImage rendering bug found in v0.99.1.

### 🐛 Fixes
- **Linux AppImage Blank Window**: The released AppImage bundles its own WebKitGTK,
  built on the CI runner rather than the end user's machine. That bundled build could
  be old enough that its accelerated compositing path rendered a completely blank
  window on some newer Mesa/Wayland driver stacks, even though a locally built
  AppImage (which bundles the host's own current WebKitGTK) worked fine. Fixed by
  disabling WebKitGTK compositing mode on Linux, alongside the existing DMA-BUF
  workaround from #370, and bumping the release workflow's Linux runner to
  `ubuntu-24.04` so future AppImages bundle a newer WebKitGTK baseline (#384).
