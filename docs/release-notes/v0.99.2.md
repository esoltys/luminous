# Release Notes - Luminous v0.99.2

Patch release removing the broken Linux AppImage distribution.

### 🐛 Fixes
- **Linux AppImage Dropped**: The released AppImage bundled its own WebKitGTK/Mesa/EGL,
  built on the CI runner rather than the end user's machine. On many host systems that
  collides with the system's own graphics stack, opening a completely blank window
  (`Could not create default EGL display: EGL_BAD_PARAMETER`). This is an
  [upstream Tauri/WebKitGTK bug](https://github.com/tauri-apps/tauri/issues/11988) —
  WebKitGTK initializes EGL before any of the documented environment-variable
  workarounds are even read, so app-level fixes aren't possible. The only real fix
  (an experimental, unreleased Tauri bundler branch) isn't stable enough to ship, so
  v0.99.2 removes `appimage` from the Linux bundle targets. Use the `.deb` or `.rpm`
  package instead, or build your own AppImage locally with `bun run tauri build` —
  a locally built one links against your own system libraries and doesn't hit this
  (#384).
