# v2.6.0

Luminous 2.6 lets you play music straight away without setting up a library, makes the Home Top Albums chart agree with Stats, respects your reduced-motion preference throughout the app, and fixes a batch of shuffle and Previous-button bugs, backed by formal Lean models of the playback state machine.

### ▶️ Play Without a Library
- **Play music from the welcome screen** ([#1256](https://github.com/esoltys/luminous/issues/1256)): with no library yet, the welcome screen now leads with Open Files and Play a Folder (or just drop files onto the window). Building a library is still a single click away as the second option.
- **Open… button**: a dedicated Open… button in the top bar, separate from search, opens files or folders to play at any time.
- **Walkthrough ends on Home**: the first-run tour now finishes on Home instead of Settings, with refreshed copy.
- **Empty pinned playlists hidden**: Home no longer shows pinned playlists that don't have any songs yet.

### 📊 Top Albums Chart
- **Local weeks on your start-of-week** ([#1259](https://github.com/esoltys/luminous/issues/1259)): Home's Top Albums chart now uses your local time zone and the "Start the week with" setting instead of UTC weeks.
- **Matches Stats**: albums are ranked by minutes played, the same measure the Stats view uses, and stats exclusions are respected.
- **Re-entry badge**: albums returning to the chart after dropping off are marked "Re-entry", and week-over-week movement is computed live from the previous week.

### ♿ Accessibility & Motion
- **Reduced motion respected** ([#1210](https://github.com/esoltys/luminous/issues/1210)): with your system's reduce-motion preference on, sliding and scaling transitions are replaced with gentle fades throughout the app.
- **Keyboard-reachable help** ([#1211](https://github.com/esoltys/luminous/issues/1211)): help text that was only shown on mouse hover now also opens on keyboard focus and closes with Escape.
- **Snappier layout shortcuts**: Ctrl+1/2/3 and Ctrl+I layout changes now apply instantly instead of animating, and a few long animations were shortened.

### 🐛 Fixes
- Fixed Next/Previous stepping from the wrong track after turning shuffle off ([#1221](https://github.com/esoltys/luminous/issues/1221)).
- Fixed Previous going to the wrong song after switching shuffle modes ([#1222](https://github.com/esoltys/luminous/issues/1222)).
- Fixed Previous not wrapping under Repeat Playlist when earlier tracks are unavailable ([#1223](https://github.com/esoltys/luminous/issues/1223)).
- Fixed Previous history pointing at the wrong songs after reordering the Queue with shuffle off ([#1232](https://github.com/esoltys/luminous/issues/1232)).
- Restored the right-click context menu on artist cards in Collection → Artists ([#1206](https://github.com/esoltys/luminous/issues/1206)).
- Fixed library scan progress staying at 0 / N during Reading Tags ([#1243](https://github.com/esoltys/luminous/issues/1243)).
- Fixed hovering a toast leaving a dark patch over detail view headers ([#1258](https://github.com/esoltys/luminous/issues/1258)).
- Fixed seeking before the first Play after launch being ignored, so playback resumed from the old position.

### ⚡ Under the Hood & Architecture
- **Lean verification of playback state machines (Epic [#1224](https://github.com/esoltys/luminous/issues/1224))**: formal Lean models of the player's shuffle and index logic, checked in CI ([#1225](https://github.com/esoltys/luminous/issues/1225)) and kept in sync with the Rust implementation by property tests ([#1226](https://github.com/esoltys/luminous/issues/1226)).
- **Engineering lessons from the MIR interface kit (Epic [#1209](https://github.com/esoltys/luminous/issues/1209))**: a lint for CSS custom properties that are read but never defined ([#1212](https://github.com/esoltys/luminous/issues/1212)), a computed-style diff tool to prove CSS refactors are visually neutral ([#1217](https://github.com/esoltys/luminous/issues/1217)), and documented motion, test-design and UI conventions ([#1214](https://github.com/esoltys/luminous/issues/1214), [#1215](https://github.com/esoltys/luminous/issues/1215), [#1216](https://github.com/esoltys/luminous/issues/1216)).
- **Rust formatting in CI** ([#1234](https://github.com/esoltys/luminous/issues/1234)): CI now fails on `cargo fmt` drift.
- Release and Flatpak workflow fixes, and dependency security updates.
