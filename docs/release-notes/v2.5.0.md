# v2.5.0

Luminous 2.5 brings remote media streaming, rich MusicBrainz and artist metadata enrichment, official Flatpak packaging, an interactive Audio Pipeline inspector, and extensive deep-module architectural refactors across the audio and playback engines.

### 🌐 OpenSubsonic & Media Servers
- **OpenSubsonic streaming & library integration** ([#916](https://github.com/esoltys/luminous/issues/916), [#1161](https://github.com/esoltys/luminous/issues/1161)): connect directly to Navidrome, Nextcloud Music, Gonic, LMS, or any Subsonic-compatible server.
- **Paging library sync** ([#1162](https://github.com/esoltys/luminous/issues/1162)): imports remote songs, albums, artists, cover art, and starred items into your unified Luminous library.
- **Hardened streaming playback** ([#1163](https://github.com/esoltys/luminous/issues/1163)): native `subsonic://` stream resolver with robust HTTP range-request support for instant seeking and gapless streaming.
- **Two-way synchronization** ([#1165](https://github.com/esoltys/luminous/issues/1165)): automatically reports scrobbles/plays back to the server and synchronizes favorites and ratings bi-directionally.
- **Flexible authentication** ([#1167](https://github.com/esoltys/luminous/issues/1167)): supports modern token+salt authentication, legacy password mode, and API key authentication.
- **Media Servers settings** ([#1164](https://github.com/esoltys/luminous/issues/1164)): dedicated server connection manager in Settings with connection testing, server switching, and graceful remote offline handling.
- **Background WebDAV sync** ([#1082](https://github.com/esoltys/luminous/issues/1082), [#1083](https://github.com/esoltys/luminous/issues/1083)): WebDAV sync now runs automatically on a periodic schedule and stays active when navigating away from Settings.

### 🔍 MusicBrainz & Artist Enrichment
- **Automatic metadata retrieval** ([#1143](https://github.com/esoltys/luminous/issues/1143)): automatically fetches artist details, portraits, and album info on detail page visits, tracked by a unified progress bar.
- **Rich artist profiles** ([#1128](https://github.com/esoltys/luminous/issues/1128), [#1146](https://github.com/esoltys/luminous/issues/1146)): displays artist gender, sort names, grouped birth/death and foundation event dates, and locations from MusicBrainz.
- **Artist portraits from fanart.tv & Wikidata** ([#1127](https://github.com/esoltys/luminous/issues/1127)): fetches high-resolution artist profile images with automatic fallback to local artwork.
- **Release-group relations** ([#1122](https://github.com/esoltys/luminous/issues/1122), [#1124](https://github.com/esoltys/luminous/issues/1124)): links albums to Discogs, AllMusic, Wikidata, and lyrics providers, complete with cached domain favicons.
- **Artist MBID persistence** ([#1123](https://github.com/esoltys/luminous/issues/1123)): stores artist MusicBrainz IDs across sessions and adds an on-demand "Retrieve Artist Details" button.

### 🎧 Audio & Formats
- **Audio Pipeline inspector** ([#1041](https://github.com/esoltys/luminous/issues/1041)): interactive signal-chain popover showing decode format, sample rate, bit depth, channels, software gain, and output device info, paired with a playbar audio quality badge.
- **Opus format support** ([#1121](https://github.com/esoltys/luminous/issues/1121)): native decoding for Opus audio files via a bundled libopus adapter.
- **Repeat Album mode** ([#1070](https://github.com/esoltys/luminous/issues/1070)): fully functional Album repeat looping alongside existing None, All, and One repeat modes.

### 🎨 Visuals & UI Polish
- **CoverMosaic** ([#1100](https://github.com/esoltys/luminous/issues/1100)): a multi-cover layout for headers, providing an alternative to CoverStack when more horizontal space is available.
- **Expanded Social Share Cards** ([#880](https://github.com/esoltys/luminous/issues/880), [#1134](https://github.com/esoltys/luminous/issues/1134)): share cards now support Playlists, Artists, and Personal Stats cards, featuring horizontal mosaic cover layouts.
- **Background task tracker** ([#1087](https://github.com/esoltys/luminous/issues/1087)): unified progress tracker in the notification panel for long-running background syncs, library scans, and metadata retrievals.
- **Playbar-only collapse** ([#1103](https://github.com/esoltys/luminous/issues/1103)): removes extra window chrome when resizing the app window down to a compact mini-player height.
- **Chart movement indicators** ([#1088](https://github.com/esoltys/luminous/issues/1088), [#1101](https://github.com/esoltys/luminous/issues/1101)): rising, falling, and new rank movement badges on Home's Top Albums widget with compact date range titles.
- **Playlist header consolidation** ([#1109](https://github.com/esoltys/luminous/issues/1109)): streamlined playlist header actions with integrated top search bar filtering and right-click context menus on playlist cards.
- **Folder smart playlists** ([#1183](https://github.com/esoltys/luminous/issues/1183)): generate smart playlists based on folder paths and subfolders directly from the library.
- **Artist-only tags** ([#1105](https://github.com/esoltys/luminous/issues/1105)): artist-specific tag counts and single-layer hierarchy in the Organize and Tag views.

### 📦 Packaging
- **Flatpak support** ([#1086](https://github.com/esoltys/luminous/issues/1086)): official Flatpak package and release workflow publishing to a self-hosted Flatpak repository.

### ⚡ Under the Hood & Architecture
- **Audio engine deep-module refactor (Epic [#1063](https://github.com/esoltys/luminous/issues/1063))**:
  - Replaced `std::sync::Mutex` with `parking_lot::Mutex` to guarantee no lock poisoning and eliminate thread allocations ([#1065](https://github.com/esoltys/luminous/issues/1065)).
  - Atomic volume control removing lock contention inside the real-time CPAL callback ([#1064](https://github.com/esoltys/luminous/issues/1064)).
  - Encapsulated audio handles into `AudioShared` and closed internal engine fields behind clean accessor methods ([#1067](https://github.com/esoltys/luminous/issues/1067), [#1068](https://github.com/esoltys/luminous/issues/1068)).
- **Player engine deep-module refactor (Epic [#1069](https://github.com/esoltys/luminous/issues/1069))**:
  - Unified the playback decision tree and centralized track start handling ([#1072](https://github.com/esoltys/luminous/issues/1072), [#1073](https://github.com/esoltys/luminous/issues/1073)).
  - Consolidated state restoration into a typed `app_state` table ([#1071](https://github.com/esoltys/luminous/issues/1071)).
  - Comprehensive unit and integration test coverage for gapless handover, scrobble triggers, and play-next queues ([#1077](https://github.com/esoltys/luminous/issues/1077)).
- **Tokio scheduler responsiveness** ([#1097](https://github.com/esoltys/luminous/issues/1097), [#1102](https://github.com/esoltys/luminous/issues/1102)): migrated remaining synchronous SQLite database queries off async worker threads to prevent runtime stalls.
