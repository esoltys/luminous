# v1.7.0

A visual refresh with a new icon set, plus fixes for tag saving and a few polish items.

### ✨ Improvements
- **New icon set**: migrated the entire app from Lucide to Phosphor icons with a Duotone default, giving controls a softer, more consistent look throughout ([#722](https://github.com/esoltys/luminous/issues/722)).
- **Home row styling unified**: songs and albums on the Home page now share the same two-line layout (title/year, artist/rating) instead of songs using a different, more cluttered card format ([#724](https://github.com/esoltys/luminous/issues/724)).
- **Copy error notification text**: error toasts now have a one-click copy button for the diagnostic message, making it easier to share or search for an error ([#727](https://github.com/esoltys/luminous/issues/727)).
- Removed a redundant "Unmark Instrumental" button in the Lyrics view — the header action button remains ([#729](https://github.com/esoltys/luminous/issues/729)).

### 🐛 Fixes
- **Tag saving no longer fails** on files with invalid embedded language codes in lyrics/comment frames, read-only file attributes, or nested encoding errors — these cases are now healed or surfaced with a clear, specific error message instead of a generic failure ([#726](https://github.com/esoltys/luminous/issues/726)).
