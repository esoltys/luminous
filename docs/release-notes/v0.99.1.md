# Release Notes - Luminous v0.99.1

Patch release with a handful of fixes found during v0.99.0 testing.

### 🐛 Fixes
- **Windows Glass Panels Restored**: The floating PlayBar, sidebar, right panel, top
  nav, and Miniplayer had lost their frosted acrylic/blur effect on Windows, rendering
  completely see-through instead. Two separate bugs, both fixed: the original
  compositing-layer issue, and a follow-up where the production build's CSS minifier
  silently stripped the standard `backdrop-filter` property, keeping only the
  `-webkit-` fallback WebView2 doesn't render (#370).
- **Miniplayer Mode Now Restores on Launch**: Closing Luminous while in Miniplayer mode
  used to reopen in Full Player mode with a brief flash of the wrong UI. Launch now
  restores the correct mode immediately (#375).
- **Balanced Drop-Down Padding**: Left-side text in pill-style drop-down menus was
  crowding the curved border; padding is now balanced with the right side across all
  views (#363).

### 🛠️ Other Improvements
- **Redesigned Update Settings**: The Application & Updates card in Settings → General
  now uses a single Never / Notify me / Install automatically policy selector, shows a
  "checked N minutes ago" timestamp, and always surfaces a Release Notes link (#379).
- **Async Update Checks on Launch**: Update checks on app launch no longer block
  startup.
- Audited the Rust test suite to remove tests that asserted nothing meaningful, and
  added an on-demand smoke test (`cargo test --test smoke_test -- --ignored`) that
  exercises real audio playback end-to-end ahead of future releases.
- Fixed a latent case-insensitive path-resolution bug on Windows caught by the test
  audit above (not previously reachable in production).
