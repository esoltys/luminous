# v3.2.0

Luminous 3.2 makes remote streaming smooth and reliable on WebDAV and Subsonic, protects your library when an external drive goes missing, brings sharper artist portraits out of the box, and shows where every set of lyrics came from — alongside large-library performance work that keeps playback responsive at startup.

### 🛡️ Library Safeguards
- **Missing drive protection** ([#1582](https://github.com/esoltys/luminous/issues/1582)): When a large share of a folder's songs vanish at once — an unplugged external drive or a renamed folder — Luminous keeps them in your library and asks before removing anything. Click **Review** on the notice, then **Keep Songs** until the drive is reconnected or **Remove Songs** to drop them. **Clean Up** asks the same question.

### 🖼️ Artwork & Lyrics
- **Sharper artist portraits** ([#1827](https://github.com/esoltys/luminous/issues/1827)): Luminous now ships with a built-in fanart.tv key, so high-resolution portraits, logos and header backgrounds work without any setup. Without a key, artist photos fall back to Deezer, then Wikidata. You can still add your own key in **Settings → Integrations**, and **Revert to Default** switches back.
- **Lyrics source badge** ([#1743](https://github.com/esoltys/luminous/issues/1743)): The lyrics view shows where the current lyrics came from — embedded tags, a sidecar `.lrc`/`.vtt`/`.srt` file, an online provider, your own edits, or the local cache.
- **WebDAV album covers everywhere** ([#1823](https://github.com/esoltys/luminous/issues/1823)): Album covers now appear in the Albums grid, album detail and other views when WebDAV is your only source.
- **Covers refresh after a rescan** ([#1755](https://github.com/esoltys/luminous/issues/1755), [#1756](https://github.com/esoltys/luminous/issues/1756)): The artist header mosaic picks up replaced covers after **Refresh Artist**, and **Refresh** on an album whose rescan renames it now finishes quietly.

### 📡 Remote Streaming
- **Stutter-free streaming** ([#1820](https://github.com/esoltys/luminous/issues/1820), [#1785](https://github.com/esoltys/luminous/issues/1785)): Remote tracks are read ahead with double buffering so the decoder never waits on the network, and background waveform and visualizer work now yields to the stream that's playing.
- **Faster, more compatible connections** ([#1809](https://github.com/esoltys/luminous/issues/1809), [#1810](https://github.com/esoltys/luminous/issues/1810)): Pooled HTTP connections and no redundant HEAD requests mean tracks start sooner, and seeking works on WebDAV servers that omit the `Content-Range` header.
- **Remote library badge** ([#1804](https://github.com/esoltys/luminous/issues/1804)): Song tables show the WebDAV badge for paths with spaces or percent-encoded characters.

### ⚡ Large Library Performance (Epic [#1812](https://github.com/esoltys/luminous/issues/1812))
- **No frontend freeze on startup** ([#1811](https://github.com/esoltys/luminous/issues/1811)): The library snapshot loads in pages with faster sorting, keeping the interface responsive on very large collections.
- **Playback ready sooner** ([#1807](https://github.com/esoltys/luminous/issues/1807), [#1806](https://github.com/esoltys/luminous/issues/1806), [#1808](https://github.com/esoltys/luminous/issues/1808)): Auto-playlist syncing no longer blocks playback at startup, library ordering uses a dedicated index, and queue replacement writes in a single transaction.
- **Smooth album grid scrolling** ([#1753](https://github.com/esoltys/luminous/issues/1753), [#1757](https://github.com/esoltys/luminous/issues/1757)): Album grid rows hold one height so scrolling no longer stutters, and rating stars stay level with or without a genre chip.

### 🎧 Playback & Appearance
- **No more underrun rebuild loops** ([#1800](https://github.com/esoltys/luminous/issues/1800)): A brief audio buffer underrun no longer triggers repeated output stream rebuilds and stuttering.
- **Albums stay together** ([#1752](https://github.com/esoltys/luminous/issues/1752)): Tracks whose album titles differ only in letter case are grouped into one album.
- **Readable themes** ([#1730](https://github.com/esoltys/luminous/issues/1730), [#1798](https://github.com/esoltys/luminous/issues/1798)): Dynamic themes from monochromatic album art and all predefined themes now meet contrast and border-separation requirements, so the equalizer curve and controls stay visible.
- **Consistent German wording** ([#1831](https://github.com/esoltys/luminous/issues/1831)): German messages now use the same informal register as the rest of the app, including the new missing-drive and fanart.tv notices.

### 🐧 Linux
- **AppImage delta updates** ([#1703](https://github.com/esoltys/luminous/issues/1703)): The AppImage embeds update information and a `.zsync` file is published with each release, so AppImageUpdate and compatible tools download only what changed.

### 🏗️ Architecture & Developer Ergonomics
- **More engine workspace crates (Epic [#1762](https://github.com/esoltys/luminous/issues/1762))**: Extracted the add-on runtime (`crates/luminous-addons`, [#1764](https://github.com/esoltys/luminous/issues/1764)), offline audio analysis (`crates/luminous-analysis`, [#1765](https://github.com/esoltys/luminous/issues/1765)), tag and sidecar parsing (`crates/luminous-metadata`, [#1766](https://github.com/esoltys/luminous/issues/1766)) and remote protocol clients including the lyrics provider cascade (`crates/luminous-remote`, [#1767](https://github.com/esoltys/luminous/issues/1767), [#1778](https://github.com/esoltys/luminous/issues/1778)) into crates with no Tauri or SQLite dependency, and folded Equalizer APO import/export into `crates/luminous-equalizer` ([#1763](https://github.com/esoltys/luminous/issues/1763)).
