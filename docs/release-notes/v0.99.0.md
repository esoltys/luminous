# Release Notes - Luminous v0.99.0

Luminous v0.99.0 is the last stop before 1.0. It's a large release — Queue rework, EQ
correctness fixes, resizable columns, full compilation (TCMP) support, and a long tail of
polish — but its real purpose is to mark **feature lock**: no new features are planned
between now and 1.0. From here, this pre-release phase is bug fixes only, driven by
whatever testing turns up. If you hit something wrong, file it at
[github.com/esoltys/luminous/issues](https://github.com/esoltys/luminous/issues) — that's
what stands between this build and 1.0.

### 🌟 New Features
- **Full Compilation (TCMP) Support**: Compilation albums (Various Artists releases) can
  now be flagged read/write via a UI toggle, with a quick-fill action to set every track's
  artist to "Various Artists" in one pass (#366).
- **EQ Correctness Fixes**: Low/high shelf filter math corrected, plus a new Headphones
  preset (#347).
- **Resizable Table Columns**: Song table columns can now be dragged wider/narrower, with
  the widths persisted per-view (#300, #307).
- **Bulletproof Queue Playback**: The Queue was reworked around UUID-based track
  navigation instead of position indices, robust M3U opening, and theme-aware Queue
  badges — fixing several of the Queue bugs below at the root instead of patching around
  them (#274).
- **Queue-Based Playlist Shuffle & History**: Shuffle now reorders the live playback queue
  instead of faking it, there's a new History auto-playlist of recently played tracks, and
  the sidebar Queue entry navigates directly to what's playing (#261).
- **Extended Metadata as Smart Playlist Filters**: BPM, Grouping, Initial Key, and other
  previously-editable-only fields are now available as Smart Playlist and search filter
  criteria (#253).
- **BPM Auto-Playlist Category**: Tracks are now grouped into BPM-range auto-playlists
  alongside the existing genre/decade ones (#301).
- **Hamburger Menu for Compact Sidebar**: A navbar toggle for collapsing the sidebar,
  independent of window width (#309).
- **Dynamic Themes Row, Metallic & Sabrina Themes**: Reorganized the theme picker with a
  dedicated Dynamic Themes row, added card footnotes, and shipped two new built-in themes
  (#336).
- **Singles as an Editable Table**: Artist Detail now lists singles as a proper
  column-aware table instead of a bare list (#297).
- **Favourite Album Corner Flag**: A Luminous-themed Heart-icon flag marks favourited
  albums directly on their cover art (#287).
- **WebP Cover Art Support**: Cover art extraction now recognizes WebP (via magic-byte
  detection instead of guessing from file extension), alongside a new manual Album Detail
  refresh button (#288).
- **Overlapping Disc Icons for Box Sets**: Multi-disc releases now show a stacked-disc
  icon on their cover (#289).
- **Update-Celebration Toast Links to Releases**: The "Updated to Luminous" toast now
  links straight to the GitHub release notes for what just installed (#252).

### 🎨 Visual & UX Improvements
- **Layered Frequency-Band Waveform**: Replaced the old moodbar with a low/mid/hi
  frequency-band waveform, centered alongside the seek bar and timers in the player bar
  (#264, #267).
- **Blurred Album-Art Backdrop**: Album Detail now shows a blurred backdrop of its own
  cover art (#275), with several follow-up passes fixing the flicker it introduced in the
  logo, glass surfaces, and sidebar (#276, #279, #282, #304).
- **Linux Acrylic/Transparent Regression Fixed**: Miniplayer and PlayerBar translucency
  broke on Linux partway through the release; restored (#360).
- **Welcome Screen & About Settings Polish**: Welcome screen now uses the Luminous logo
  mark instead of a generic icon (#266); About settings gained Homepage/Discussions/Issues
  links and an updated tagline (#263).
- **Sort & Navigation Refinements**: Date Added sort option for the album collection with
  standardized triangle-first sort menus (#278), relative Date Added display and
  duration-based EP classification (#290), and arrow-key navigation from the search bar
  into its results dropdown (#291).
- **Auto-Playlists Renamed & Tidied**: "Favourites" is now "Favourite Songs" for clarity
  (#292); the Queue is now consistently excluded from Home rows, artist playlists, and
  reserved-name checks (#271, #299).
- **Playlist Header Scrolls With Content**: Stopped pinning the playlist header above
  scrolled content (#280).
- **Native Desktop Cursor & Chrome Cleanup**: Removed the leftover web hand/pointer
  cursor on interactive elements (#313), and removed the album count from the Artist
  Detail subheading to reduce clutter (#310).
- **Monospace Font Bugs**: Song table columns (#365) and the Date Added/Last Played
  columns (#281) were mistakenly rendering in a monospace font; both fixed.
- **Bulk Edit & Carousel Fixes**: Album bulk edit now allows saving an empty genre or
  disc tag, alongside a refactor of the artist release carousels (#285).

### 🐛 Stability & Bug Fixes
- **Queue Desync Bugs**: Adding/removing tracks in the Queue wasn't reflected in live
  playback (#270), album songs weren't appending to the queue correctly and the toast
  didn't name the album (#283), the sidebar queue count didn't update as songs were added
  (#284), the Queue's cover icon ignored the active theme accent (#342), and play context
  wasn't threaded through queue-routed playback (#314) — largely superseded by the Queue
  rework above (#274) but tracked individually as they landed.
- **Untagged Songs Breaking Navigation**: Songs missing artist tags could break artist
  navigation entirely and freeze cover art loading elsewhere in the app (#364).
- **Spurious Watcher Toasts & False Playback-Error Skip**: The file watcher could fire
  incorrect toasts and, separately, skip a track on a false-positive playback error
  (#361).
- **Case-Only Rename Bugs**: Renaming a folder's casing only (e.g. "HERO" → "Hero") on a
  case-insensitive filesystem still had edge cases — duplicate/cycling entries in Organize
  Files and Artists view (#302), an `ENOENT` when an ancestor folder's case-fix relocated a
  file before its own rename ran (#354), and stale-cased paths now self-heal on playback
  failure on Linux instead of just failing (#357).
- **Playlist Undo Restoring Wrong Position**: Undoing a playlist edit could put the
  restored item back in the wrong spot (#353).
- **Dead Click on Albumless Songs**: Songs without an album in Home's Recently Added
  weren't clickable (#306).
- **System Audio Output Device Changes**: Playback now follows OS-level default output
  device switches instead of getting stuck on a disconnected device (#259).
- **AppImage Builds on Rolling-Release Distros**: Fixed builds failing on Arch/CachyOS-
  style rolling releases (#348).
- **Auto-Playlist Actions Relocated**: Moved into the overflow menu to match the rest of
  the playlist toolbar redesign (#272).
- **Security**: Resolved Dependabot advisories for `nanoid` and `glib` (#337), and added a
  standing cargo security audit workflow (#315).

### 🔧 Under the Hood
- **IPC Boundary Deepening**: Continued shrinking the Tauri IPC surface — Queue
  abstraction, error diet, deeper EQ/prefs commands, always-complete dynamic playlists
  (#346), and follow-up passes on playlists and Queue live-sync (#351, #352, #359).
- **Docs Reorganized**: Docs moved into folders, with new documentation for the Rust
  backend's core modules (#358).
- **Routine dependency updates** across the Rust and JS toolchains (Symphonia, Tokio,
  Vite, Svelte, TypeScript, and others), plus assorted CI and build-warning fixes.

Since v0.99.0 is the first release able to receive a signed in-app update (the updater
plugin landed in v0.98.0 with nothing yet to update *to*), this is also the first release
where auto-update actually activates for anyone running v0.98.0 or v0.98.1.
