# v1.8.0

MusicBrainz/AcoustID metadata now surfaces in the Info Panel, plus a batch of playback UI fixes.

### ✨ Improvements
- **MusicBrainz & AcoustID metadata in the Info Panel**: recordings, tracks, and works tagged by MusicBrainz Picard now show their linked MusicBrainz identities, AcoustID, and release metadata (label, catalog number, format, bitrate) right in the sidebar, with clickable links out to MusicBrainz ([#752](https://github.com/esoltys/luminous/issues/752)).
- The Info Panel toggle moved from the top nav into the player bar for quicker access ([#752](https://github.com/esoltys/luminous/issues/752)).

### 🐛 Fixes
- **Scrollbars restored** on song-table views (Songs, Albums, Artists, playlists) that had lost their vertical scrollbar ([#792](https://github.com/esoltys/luminous/issues/792)).
- **Fixed a blank window** that could appear when restoring Luminous after it was minimized on Windows ([#789](https://github.com/esoltys/luminous/issues/789)).
- **Fixed box set disc icons** no longer displaying on cover art ([#750](https://github.com/esoltys/luminous/issues/750)).
- **Fixed the miniplayer toggle disappearing** in the player bar below the 700px width breakpoint ([#795](https://github.com/esoltys/luminous/issues/795)).
- **Fixed the play/pause button's icon** sitting visibly off-center ([#796](https://github.com/esoltys/luminous/issues/796)).
- **Fixed Album/Artist Detail views** showing "Unknown Artist"/"Unknown Album" after renaming via the tag editor, until navigating away and back ([#797](https://github.com/esoltys/luminous/issues/797)).
- Removed a misleading "Country" row from the Info Panel, which showed an arbitrary MusicBrainz release-event territory rather than the artist's home country ([#770](https://github.com/esoltys/luminous/issues/770)).
