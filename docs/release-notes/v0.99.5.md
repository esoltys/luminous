# Release Notes - Luminous v0.99.5

Infrastructure-only patch release fixing several Microsoft Store (MSIX) packaging issues
found during certification; no user-facing changes on other platforms.

### 🛠️ Other Improvements
- **MSIX file-system access declared**: the manifest was missing the
  `broadFileSystemAccess` capability, which the Store install needs to browse and import a
  user's music library from arbitrary folders.
- **Self-update UI hidden for Store installs**: Microsoft Store builds are updated by the
  Store, not the in-app updater — the update-check settings pane and self-update logic are
  now disabled when running as an MSIX install.
- **App tile fixed**: the MSIX start-menu tile rendered as a plain black square instead of
  the app icon; it now uses the square app icon, and the `DefaultTile` manifest entry that
  was causing the invalid tile is fixed.

This release exists to unblock the pending Microsoft Store submission. There are no
changes to the app itself.
