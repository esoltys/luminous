# v4.1.0

Luminous 4.1 brings live **Internet Radio** with a built-in directory, custom stations, and station playlists; a new collection of **Built-in Visualizers**; **two-way synced File playlists**; **faster unchanged library scans**; and dozens of playback, library, and interface fixes.

### 📻 Internet Radio (Epic [#2001](https://github.com/esoltys/luminous/issues/2001))
- **Discover, browse, and play live stations** ([#2003](https://github.com/esoltys/luminous/issues/2003), [#2005](https://github.com/esoltys/luminous/issues/2005), [#2007](https://github.com/esoltys/luminous/issues/2007)): Browse and search the Radio Browser directory directly from the new Internet Radio tab and global search, or find stations currently playing your song ([#1998](https://github.com/esoltys/luminous/issues/1998)).
- **Live queue playback & metadata** ([#2002](https://github.com/esoltys/luminous/issues/2002), [#2004](https://github.com/esoltys/luminous/issues/2004), [#2008](https://github.com/esoltys/luminous/issues/2008)): Play stations seamlessly as queue items with automatic reconnects and live now-playing track info across the UI.
- **Custom stations, playlists & pinning** ([#2006](https://github.com/esoltys/luminous/issues/2006), [#2009](https://github.com/esoltys/luminous/issues/2009), [#2010](https://github.com/esoltys/luminous/issues/2010), [#2209](https://github.com/esoltys/luminous/issues/2209), [#2279](https://github.com/esoltys/luminous/issues/2279), [#2310](https://github.com/esoltys/luminous/issues/2310)): Add stations by URL, import streaming playlists, auto-update genre station lists, pin stations, toggle between card and compact rows with drag-and-drop reordering, and view station context (Wikidata, Wikipedia, website) in the Info sidebar.
- **HLS & HE-AAC streams** ([#2011](https://github.com/esoltys/luminous/issues/2011), [#2012](https://github.com/esoltys/luminous/issues/2012), [#2203](https://github.com/esoltys/luminous/issues/2203)): Stream HLS stations and decode full-quality HE-AAC (AAC+) streams on Windows (Media Foundation) and Linux (`libavcodec`).

### 🎨 Built-in Visualizers (Epic [#2244](https://github.com/esoltys/luminous/issues/2244))
- **Immersive visualizer & playbar mini-view** ([#2236](https://github.com/esoltys/luminous/issues/2236), [#2242](https://github.com/esoltys/luminous/issues/2242), [#2245](https://github.com/esoltys/luminous/issues/2245)): Switch between presets with a unified selector, playbar mini-visualizer, and bass-flux beat signal ([#2246](https://github.com/esoltys/luminous/issues/2246)).
- **New presets**:
  - **Voxel Spectrum & Waterfall** ([#2236](https://github.com/esoltys/luminous/issues/2236), [#2306](https://github.com/esoltys/luminous/issues/2306)) and **Voxel Logo** with beat ripples ([#2252](https://github.com/esoltys/luminous/issues/2252), [#2270](https://github.com/esoltys/luminous/issues/2270)).
  - **Stereo Vectorscope** with correlation, loudness, and true-peak meters ([#2247](https://github.com/esoltys/luminous/issues/2247)).
  - **VU Meter** modeled after the Yamaha K-550 ([#2360](https://github.com/esoltys/luminous/issues/2360)).
  - **Salmon Run** isometric voxel river with fish ladder, bears, interactive frog, and foliage ([#2248](https://github.com/esoltys/luminous/issues/2248), [#2302](https://github.com/esoltys/luminous/issues/2302), [#2397](https://github.com/esoltys/luminous/issues/2397)).

### 📁 Playlists, Library & Performance
- **Two-way synced File playlists** ([#2280](https://github.com/esoltys/luminous/issues/2280)): Import playlist files from your library as File playlists that stay in sync on disk.
- **Faster unchanged scans** (Epic [#2355](https://github.com/esoltys/luminous/issues/2355)): Reduced per-file stat overhead ([#2353](https://github.com/esoltys/luminous/issues/2353), [#2366](https://github.com/esoltys/luminous/issues/2366)), added file size to unchanged checks ([#2352](https://github.com/esoltys/luminous/issues/2352)), skipped redundant DR log and artwork passes ([#2367](https://github.com/esoltys/luminous/issues/2367)), and optimized SQLite reconciliation ([#2368](https://github.com/esoltys/luminous/issues/2368)).
- **Opt-in background integrity & provenance checks** ([#2189](https://github.com/esoltys/luminous/issues/2189)): Toggle background integrity and provenance verification in Settings.

### ✨ Interface & Documentation
- **Fullscreen mode** ([#2231](https://github.com/esoltys/luminous/issues/2231), [#2314](https://github.com/esoltys/luminous/issues/2314), [#2372](https://github.com/esoltys/luminous/issues/2372)): Toggle fullscreen with `Ctrl+Shift+F` or `F11` (exit with `Esc`), with the immersive cover view scaling to the screen.
- **Streamlined navigation & Help** ([#2191](https://github.com/esoltys/luminous/issues/2191), [#2230](https://github.com/esoltys/luminous/issues/2230), [#2234](https://github.com/esoltys/luminous/issues/2234), [#2239](https://github.com/esoltys/luminous/issues/2239)): Moved Connect/Connected below Settings, Application & Updates to About & Credits, and Report a bug / Get help onto the Help page.
- **Updated user guide & screenshots** ([#2254](https://github.com/esoltys/luminous/issues/2254), [#2255](https://github.com/esoltys/luminous/issues/2255), [#2256](https://github.com/esoltys/luminous/issues/2256), [#2257](https://github.com/esoltys/luminous/issues/2257)): Refreshed documentation and screenshots across all seven languages.
