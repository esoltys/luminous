# v1.6.0

A small fix-focused release.

### 🐛 Fixes
- **Album Artist no longer forced to "Various Artists"** when editing a compilation-flagged album or track that actually has a real album artist name ([#690](https://github.com/esoltys/luminous/issues/690)).
- **Immersive (album-art) view typography** now matches the player bar's title/album/artist order and hierarchy, and no longer shifts the cover art's centered position depending on text length ([#701](https://github.com/esoltys/luminous/issues/701)).
- **Custom playlist song table** background is now consistent, and a blurred artifact no longer sticks on row hover ([#665](https://github.com/esoltys/luminous/issues/665)).
- **AcoustID API key no longer logged in cleartext** ([#656](https://github.com/esoltys/luminous/issues/656)).

### 🛠️ Internal
- Removed Flatpak/Flathub packaging and submission automation entirely — Flathub's Generative AI policy prohibits AI-automated submission PRs, which is how the prior submission was carried out.
- Removed winget manifest automation and CI checks; Luminous's existing winget listing is unaffected.
- Added a `/issue` skill for milestone-aware issue pickup (development tooling only).
